Abstract

Urban Digital Twins (UDT) integrate heterogeneous geospatial, environmental, and semantic data with varying spatial and temporal resolutions, but their use often remains limited to experts who operate GIS tools, domain-specific APIs, or bespoke dashboards. In this context, we present CityBot, a conversational user interface (UI) to explore the UDT of Sofia, Bulgaria.

Building on a WoT-based architecture for integrating LLM agents with heterogeneous systems, CityBot develops an urban-specific affordance model that exposes six resources: a semantic 3D city model, historical air-quality data, ML-based pollution forecasts, a multi-operator environmental sensor network, Wikipedia-grounded building knowledge, and live weather and geocoding services. An LLM maps free-form requests to typed WoT actions, while a Cesium frontend renders navigation, semantic filtering, pollution replay, and forecast visualizations on an interactive 3D globe. The demonstration allows users to issue their own natural-language requests and directly observe the resulting multi-step interactions with Sofia’s UDT.

Contributions

  • An LLM agent for natural-language interaction with a UDT, implemented through a WoT-based affordance model for navigation, semantic building interaction, environmental queries, historical pollution replay, and forecast visualization.
  • A six-resource integration spanning a semantic 3D city model, historical air quality, pollution forecasts, a multi-operator environmental sensor network, Wikipedia-grounded building knowledge, live weather, and geocoding services.
  • A bidirectionally synchronized conversational interface in which LLM-selected actions update the Cesium globe, while camera and building state context ground subsequent user requests.

Index Terms— Urban Digital Twin, Smart City, Web of Things, Large Language Model, Agent.

System Architecture

Components

Domain Things host
Exposes four Domain Things with W3C Thing Descriptions over HTTP/MQTT: citymodel, airquality, api, knowledge.
LLM Thing
Multi-turn planning loop: injects camera and selected-building context, invokes WoT actions as tools, and supports Whisper STT and Kokoro TTS via DeepInfra.
Domain Things
Adapt heterogeneous urban services—CityGML 3D tiles, PostgreSQL air quality, sensor feeds, Nominatim, OpenWeatherMap, Qdrant RAG—to a common affordance model.
UI client
Cesium.js WoT consumer: MQTT-driven map updates, incremental response streaming, and bidirectional shared context with the LLM Thing.

Things

Each Thing publishes a W3C Thing Description at its HTTP endpoint. Action forms are bound to HTTPS; map-state and stream events are delivered over MQTT.

Demonstration Walkthrough

The sequence below follows a user exploring Sofia through natural-language requests. Each step combines a different mix of data access, tool chaining, and visual feedback.

  1. “Load the 3D model of Sofia, colored by walkability.”

    loadTiles followed by setVisualizationStyle—graduated colors from per-building walkability scores.

  2. “Which buildings have the worst walkability index? Color them purple.”

    filterBuildings with walkability threshold <30 and a purple highlight.

  3. “Show hospitals in red and schools in blue and also sensors.”

    OR-mode filterBuildings (healthcare / schools) plus loadSensors map pins.

  4. “Are there any elevated sensors around this building?”

    filterSensors with nearPoint and elevatedOnly=true, using the selected building’s coordinates.

  5. “Remove the filter and sensors.”

    filterBuildings with filterType=none and removeSensors.

  6. “Replay PM10 pollution on 31 December 2023 for 24 hours.”

    replayPollution (parameter=PM10)—CAQI-colored clouds animated hour by hour.

  7. “Now show the next 24-hour forecast.”

    replayPrediction—ML forecast grid with the same cloud representation.

  8. “Remove the clouds.”

    clearPollutionClouds clears the animated overlay.

  9. “Tell me about this building. Who was the architect?”

    Selected-building wiki_pageid drives getWikipediaSummary and Qdrant retrieval (e.g. National Palace of Culture).
